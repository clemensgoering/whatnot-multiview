## The idea in one paragraph

Whatnot shows one stream at a time, and browser tabs do not solve it — every tab
keeps playing audio and you end up hunting for the one that is talking. MultiView
puts the streams in a grid and gives each tile its own volume slider, a mute
button and a solo button. Press `1`–`9` to hear exactly one stream and silence
the rest, without ever pausing the others.

## Keyboard reference

| Key | Action |
| --- | --- |
| `1`–`9` | Solo tile 1–9 (press again to release) |
| `0` | Release solo |
| `M` | Mute everything / restore |
| `Esc` | Leave focus mode |
| `F11` | Fullscreen |
